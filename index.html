GEB (Jeb) - Ducking and Sidechain Routing Guide

GEB / DIH World Audio / Ducking and Sidechain Routing Guide / Control - Route - Balance

GEB is the visual identity for routing guidance only. It does not rename ANUBIS or any other DIH processor, and it does not change DSP, factory presets, parameter IDs, or plugin identifiers.

1. KEY / TRIGGERThe source signal that controls attenuation. It can travel on a detector-only bus.
2. TARGETThe audible program or wet return being processed. It is not the key bus.
3. DUCKINGGain reduction while a valid key is active. Measure it in the host; this page has no meter feed.
4. RECOVERYThe target returns toward normal after the key falls. Check it in program gaps and tails.
GEB routing safeguards

A No Output detector bus is never an audible return. A wet effect return needs an audible destination. In the alternate unity-collector route, the collector main output remains No Output while its documented downstream send feeds the audible return. Keep trigger, target, return, and master paths independent to prevent feedback or accidental doubled audio.

Jeb uses your browser's available system voice. This control reads documentation; it has no connection to Logic meters or plug-in DSP.

Original workflow: TEHUTI → ANUBIS on Bus 32

Track 1 vocal/narration stays audible and has a send to Bus 32 (send level adjustable). Bus 32 is a detector-only auxiliary with output No Output. Track 2 music runs TEHUTI first, then ANUBIS (preset TEHUTI DUCK GUARD [Stereo], Sidechain Key OFF, Sidechain Duck ON). ANUBIS selects Bus 32 in its Side Chain menu; TEHUTI's selection is independent and subject to its own validation. This architecture is preserved; the alternate collector mode below is an addition, not a replacement.

Three routing modes, kept distinct

A · Detector only

Source track → Bus 32 → external plugin sidechain. Bus 32 aux: No Output. The source stays audible through its normal output.

B · Conventional wet return

Source → effects bus → reverb/delay → ANUBIS if selected → audible return aux → mix. The return outputs to the mix.

C · Alternate Unity Collector

Source → unity send → collector aux (No Output, reverb/delay then ANUBIS) → separate aux send that sets the audible amount → destination bus → audible return aux → mix. A valid configuration, not an error. Signal delivery from a No Output collector's send was verified in Logic 12.2 on 21 November 2026 (see the Mode C section).

No Output on a main output is not the same as disabling that aux's sends. A detector or collector aux may be No Output; anything meant to be heard needs an audible output.

Mode C · Alternate Unity Collector: what Logic Pro 12.2 measured

Source → normal output plus a unity send → collector aux (reverb/delay, then ANUBIS; main output No Output) → separate aux send → destination bus → audible return aux → mix. This section lists what was measured on 21 November 2026 and what is still untested. The editable Mode C settings appear below when you pick the Mode C workflow.

Mode C measured in Logic Pro 12.2 (21 November 2026) — what is verified and what is not

Setup tested: Audio 1 vocal (34 s) → Stereo Out + Send 1 at 0 dB → Bus 36 → collector aux (SacredVerb at WET MIX 1.00, then ANUBIS: Side Chain = Audio 1, DUCK ON, KEY OFF, Range −19.8, Threshold −80.0, Attack 1.6, Release 48.5; main output No Output) → Send 2 → Bus 37 → return aux → Stereo Out. Offline bounces, WAVE 24-bit 48 kHz; report CLAUDE_MODEC_FULL_TESTS_20261121.md.

  • Source stays audible, no doubled dry: with the return off the bounce equals the dry vocal bit-exactly (residual −240 dB). The return itself carries no dry vocal (correlation with the dry at lag 0 about −0.07).
  • No Output collector delivers: Send 2 on → return present; Send 2 power off → bit-exact silence. The destination aux is audible (muting it removes the return).
  • Pre/post: Logic's default for this send is Post Pan. With the collector fader at −12 dB: Post Pan −12.1/−11.7/−12.5 dB, Post Fader −12.1/−11.8/−12.1 dB, Pre Fader −0.2/+0.2/+0.3 dB. Post follows the collector fader; Pre ignores it.
  • ANUBIS ducks and recovers: about −19.8 to −20.3 dB on the wet return during phrases (full depth within about 20 ms); recovered to about 0 dB by about 0.4 s after a phrase ends, and the reverb tail after the last phrase matches the unducked tail (within about 1 dB). A 0.84 s gap recovers to about −1 dB before the next phrase.
  • Detector independence: Send 2 at −6 dB scaled the return by −6.0 dB with an unchanged duck pattern; ANUBIS meters read the same (IN 68 %, DUCK −19.8 dB) with Send 2 at 0 or −6 dB or the return aux muted; the duck is the same with the source track's main output set to No Output.
  • Save / reopen and realtime: Side Chain, Duck and Range persisted after quit and reopen; offline, reopened and realtime bounces agree within 0.1–0.5 dB. SacredVerb's reverb is not sample-identical between renders (return correlation 0.31–0.44), so wet levels, not sample nulls, are the valid comparison.
  • SacredVerb Reverb Duck: shipped default 50.00 (keyed from its own Side Chain) adds about 2–5 dB of extra duck. Set 0.00 for Mode C. Changing the default needs the next canon build.
  • Not yet tested in Mode C: TEHUTI, LookOut, SILVER and mono sources as the collector/detector, other reverbs or delays, other Logic versions, and a detector bus (instead of the Audio track) as the ANUBIS key.

Editable Logic bus assignments

Bus 32 is the owner's working vocal detector reference; all other numbers are examples. A detector bus must never share a number with an audible target or return.

Detector feed (modes A and B)

The source send level and the detector aux fader are separate controls. 0 dB is the unity reference, not a required setting. Pre/post is always stated in the generated steps.

Alternate Unity Collector → Separate Return (mode C)

In this DIH alternate route, the collector main output stays No Output. Put ANUBIS after the reverb/delay on the collector. The additional collector-to-return send dictates how much processed reverb/delay is actually heard. The return-send mode now defaults to Logic's own default (Post Pan), which was measured to follow the collector fader; Pre-fader was measured to ignore it. Choose deliberately: it decides whether the collector fader is part of the wet amount.
